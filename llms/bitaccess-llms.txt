# Bitaccess

> Bitaccess is a Canadian blockchain company (Ottawa, founded 2013, Y Combinator) that builds enterprise software and hardware to power Bitcoin ATM (BTM) operations and fintech businesses in 15+ countries. Its products include the Bitaccess BTM software platform, the Cash API for cash-in/cash-out crypto flows, and the Catena blockchain suite for publishing datasets to public/private blockchains. First-party developer libraries are published as open source under the npm @bitaccess scope and the github.com/bitaccess organization.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public catalog record. Bitaccess does not publish a machine-readable OpenAPI, AsyncAPI, or a /.well-known discovery surface at this time.

## Products
- [Bitaccess BTM](https://bitaccessbtm.com): Bitcoin ATM operating software and hardware for operators
- [Cash API](https://www.bitaccessbtm.com/cash-api): Cash-in/cash-out crypto transaction API for BTM operations
- [Catena Blockchain Suite](https://explorecatena.com): Publish complex datasets to public/private blockchains via smart contracts
